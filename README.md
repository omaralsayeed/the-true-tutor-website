# The True Tutor

An innovative educational ecosystem meticulously engineered to streamline administration and elevate the learning experience. "The True Tutor" merges advanced functionality with an intuitive, human-centered design, making it a standout solution in the education technology landscape.

---

## Key Features

- **Comprehensive Administration:** Reservations, notifications, material management, and student oversight—all from a centralized dashboard.
- **Dynamic Quiz Creation:** Design interactive quizzes with diverse question types, rich media integration, and custom scoring.
- **Robust Quiz Management:** Folder-based organization, real-time progress tracking, detailed analytics, and bulk operations.
- **Engaging Lecture Modules:** Upload lectures with multimedia components, generate unique enrollment codes, and **manage payments through an integrated Paymob gateway**.
- **Student-Centric Interface:** Effortless enrollment, material sorting by type, and interactive assessments with live feedback.

---

## Admin Panel

### Reservations
- Capture essential student registration details (name, phone, email, course preferences).
- Validate and approve applications with a streamlined process for account creation and group assignments.
- Automatically dispatch credentials via email or other messaging platforms.

### Notification Sender
- Dispatch targeted messages to specific groups.
- Schedule notifications with defined expiration dates to ensure timely communication.

### Material Uploader
- Upload PDF resources and assign them to targeted groups.
- Categorize materials (e.g., assignments, guidelines) with sorting options based on name or upload date.

### Quiz Creator – The Crown Jewel
- **Question Diversity:**  
  Develop quizzes featuring single/multiple choice, fill-in-the-blanks, free text, matching, and voice-based questions.
- **Rich Content Integration:**  
  Leverage a sophisticated WYSIWYG editor to embed images, audio, video, and files within questions, passages, and feedback.
- **Interactive Layout:**  
  Organize questions across multiple pages, with options to attach passages for enhanced context.
- **Custom Settings:**  
  Tailor quiz duration, attempt limits, randomization of questions/options, navigation controls, and live progress tracking.
- **Pre-Launch Preview:**  
  Preview quizzes in the exact format seen by students, ensuring flawless delivery.

### Quizzes Control
- **Folder-Based Management:**  
  Organize quizzes into collapsible folders with integrated search and sorting functionalities.
- **Action Suite:**  
  - Rename, edit, or delete quizzes.
  - Configure publish settings, including setting exceptions for restricted access.
  - Download quizzes as PDF.
  - Access Radar Reports: view detailed analytics on quiz attempts, including student IDs, attempt dates, and category-specific scores (with customizable table views displaying username, full name, date, score, duration, and attempts count).
  - Monitor live student responses via real-time progress tracking.
  - Utilize bulk actions: copy, merge, or move multiple quizzes simultaneously.

### Quizzes Recycle Bin
- Store deleted quizzes for 30 days before permanent removal, providing a safeguard against accidental deletion.

### Lecture Uploader
- Upload lectures with detailed metadata including title, target groups, pricing, thumbnails, and expiration settings.
- Integrate multiple lecture parts such as videos, PDFs, or quizzes (newly created or pre-existing).

### Lecture Code Generator
- Generate unique enrollment codes for lectures, ideal for facilitating manual payments.
- Integrated with the Paymob payment gateway, supporting transactions via visa/debit cards, e-mobile wallets, or kiosk reference codes.

### Lecture Control
- Manage uploaded lectures with options to edit details, delete content, or invalidate existing enrollment codes.

### Student Viewer
- Access and manage comprehensive student records.
- Search, sort, and update student details, including group assignments.

### Student Progress Tracker
- Analyze individual performance with bar charts showcasing quiz scores over time.
- View detailed reports including quiz names, dates, and category-specific scores.
- Provide template feedback and download comprehensive progress reports as PDF for parental review.

## Student Panel

### Enrollment & Lecture Access
- **Seamless Enrollment:**  
  Register or purchase lectures effortlessly through the **integrated payment gateway**.
- **Lecture Navigation:**  
  Browse lectures with customized thumbnails, pricing, and expiration data.

### Material Access
- **Curated Content:**  
  Access uploaded materials, organized by type (e.g., assignments, guidelines).
- **Efficient Sorting:**  
  Filter materials by name or upload date for quick retrieval.

### Interactive Quizzes
- **Engaging Assessments:**  
  Attempt quizzes designed with dynamic layouts and interactive elements.
- **Live Feedback:**  
  Benefit from real-time grading and progress tracking to enhance learning outcomes.
